ZenCommunity isn’t just another community plugin. It’s the *first WordPress solution* that combines the three strongest engagement systems — *Community, Real-Time Chat,* and *Support Tickets* — together in one place.

Most WordPress websites use 3–5 different tools to achieve what ZenCommunity does alone. That creates scattered conversations, missed messages, and poor user experience. ZenCommunity removes that problem completely.

By keeping community posts, chats, and support inside one system, your users stay connected, engaged, and supported without ever leaving your site.
Below are the core sections that show how ZenCommunity stands out.

=== Community Features — Your Full Social System Inside WordPress ===
ZenCommunity gives you everything needed to build a full, social-style community inside WordPress — no third-party platforms, no separate plugins.

==== Advanced Community Groups ====
Build public or private groups with full admin control. Groups can be used for LMS classes, client spaces, internal teams, membership circles, or interest-based communities. Each group has its own feed, members, and settings.

==== Facebook-Style Posting & Engagement ====
Your members can publish posts, attach media, use @mentions, comment, reply, react, and follow discussions. The interface feels familiar, simple, and fast — encouraging users to talk and stay active.

==== Real-Time Community Chat ====
ZenCommunity includes built-in chat inside groups. Members can start private one-to-one chats or chat as a group with typing indicators, read status, file sharing, and notifications. Conversations stay active without page reloads.

==== User Profiles & Activity Tracking ====
Each user gets a profile with activity, groups, posts, and engagement. This makes your community feel more personal and interactive.

==== Community Growth Features ====
Hashtags, polls, surveys, leaderboards, bookmarks, and email summaries help keep engagement high. Members always have a reason to come back.

==== Admin Control & Community Safety ====
Moderators can manage posts, approve members, customize branding, set privacy rules, and control roles. You decide how open or private each group should be.

=== Support Ticketing — Full Helpdesk Inside Your Community ===
ZenCommunity includes a complete support ticketing system connected directly to your community and chats.

==== Convert Posts Into Support Tickets ====
If a user posts a question that needs deeper help, convert it into a ticket with one click — no platform switching.

==== Clear Ticket Assignments ====
Assign each ticket to a responsible team member so the right person handles the issue. This reduces confusion and improves response time.

==== Status Tracking ====
Each ticket has clear stages (new, ongoing, solved, etc.) so both sides can follow progress. Your support team stays organized, and users always know what’s happening.

==== Personal Support Chat on Each Ticket ====
Tickets include an instant one-to-one chat. Users don’t need email or external help desks — everything is live and inside your site.

==== Smart Notifications ====
Both users and team members get notifications when ticket updates happen. Nothing gets lost.

==== Auto Replies ====
Helpful for off-hours, acknowledgment messages, or routing requests.

== Source Code ==

The compiled JavaScript and CSS in `assets/build/` are generated from human-readable sources kept in the public repository:

https://github.com/kodezen/zencommunity

* JavaScript/React sources: `dev_zencommunity/` (admin app in `dev_zencommunity/Admin/`, block editor integration in `dev_zencommunity/fse/`)
* Build configuration: `package.json`, `webpack.config.js`, `tailwind.config.js`, `tailwind.admin.config.js`, `postcss.config.js`
* PHP dependencies: `composer.json`

To build the assets yourself:

1. Clone the repository and install Node.js 20 or later and Composer.
2. Run `npm ci --legacy-peer-deps`, then `npm run build` (compiles everything into `assets/build/`).
3. Run `composer install` to install the PHP dependencies.

== External services ==

ZenCommunity works entirely on your own site. It contacts an external service only in the cases below.

= Kodezen usage insights and deactivation feedback (store.kodezen.com) =

ZenCommunity uses the StoreEngine SDK to talk to Kodezen's store at https://store.kodezen.com/.

* **Usage insights (opt-in only).** After installation, an admin notice asks whether you want to share usage data. Nothing is sent unless an administrator clicks "Allow". If you allow it, the plugin sends: site URL and name, admin name and email, server IP address, operating system, WordPress/PHP/MySQL and server versions, PHP settings and extensions, locale, multisite status, the active theme, active and inactive plugins, and the plugin version. After that it reports the same data about once a week. You can opt out at any time under ZenCommunity → Settings → License.
* **Deactivation feedback.** When you deactivate the plugin, an optional form asks why and lists what will be sent. Only if you click "Submit & Deactivate" does it send the reason, any comment you type, your name and email, the site name and URL, and the usage data listed above. Choosing "Skip & Deactivate" sends nothing.

This service is provided by Kodezen: [Terms of Use](https://kodezen.com/terms-and-conditions/), [Privacy Policy](https://store.kodezen.com/privacy-policy/).

= Links to other Kodezen products =

The "Extend your Community" dashboard section and the Live Chat settings link to product pages and downloads on https://store.kodezen.com/. These are plain links that open in your browser, and no data is sent until you click one. Products hosted on WordPress.org (for example GameEngine, GemBooking and Zaplane) are installed only when an administrator clicks "Install". They come from WordPress.org through WordPress's own plugin installer.
